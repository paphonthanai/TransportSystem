จุดที่จับคู่ด้วย "ชื่อ/ข้อความ" (ตรวจก่อนเมื่อข้อมูลไม่ขึ้น)

  • งาน → ลูกค้า: customer = ชื่อลูกค้า
  • งาน → รถ: plate = ข้อความทะเบียน (เรทน้ำมัน, เลขไมล์, รายได้รถร่วม)
  • งาน → น้ำมัน: จังหวัด + อำเภอ ต้องสะกดตรงกับตั้งค่าน้ำมัน
  • งาน → สต๊อก: ชื่อสินค้า
  • รายได้คนขับ / รายการหัก / สถานะจ่าย: ชื่อคนขับ + รอบเดือน (พ.ศ.)
  • งาน → ต้นทาง: pickupOriginName

ข้อมูลที่ไม่ได้อยู่ใน Firestore

  • Log การแก้ไขงาน (tms_logs_v1) เก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น: เครื่องอื่นมองไม่เห็น
  • รอบวางบิลแบบเก่า (tms_batches_v3) และเอกสารเก่า (tms_documents_v2): localStorage
  • ไฟล์แนบ/หลักฐานชำระในเอกสารขาย เก็บเป็น Base64 ในเอกสารเลย
  • Dashboard, งานสะสม, ยอดค้างรับ, รายได้คนขับ: คำนวณสดทุกครั้ง ไม่ได้บันทึก
