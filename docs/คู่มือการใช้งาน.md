## 1. กติกาหลักที่ต้องรู้

| เรื่อง | กติกา |
|---|---|
| ราคาน้ำมัน | เก็บเป็น **ราคาประจำวัน** แยกตามประเภทรถ งานแต่ละงานใช้ราคาล่าสุดที่ **ไม่เกินวันที่สร้างงาน** (งานนำเข้า Excel = วันที่นำเข้า) |
| เบี้ยเลี้ยง กับ ค่าน้ำมัน | เป็นรายจ่ายคนละก้อน **รายจ่าย = เบี้ยเลี้ยง + ค่าน้ำมัน** เบี้ยเลี้ยงไม่ผูกกับเรทน้ำมัน |
| รายได้บริษัท | รถบริษัท = ยอดขาย − 1% − (ค่าน้ำมัน + เบี้ยเลี้ยง) · รถหุ้นส่วน/รถอู่เสริม = (ยอดขาย − 1%) × 8% · รถร่วม = (ยอดขาย − 1%) × 10% |
| มีงานต้องมีทะเบียน มีทะเบียนต้องมีคนขับ | คนขับผูกกับรถประจำ ถ้าขาดอย่างใดอย่างหนึ่ง ระบบเติมจากรถ/คนขับประจำให้ (พร้อมเตือนให้ตรวจ) |
| ลิตรน้ำมัน | สูงสุด **200 ลิตร** (หรือลิตรมาตรฐานของปลายทางถ้าสูงกว่า เช่น เชียงใหม่ 220/230) |
| งานที่คิดเงินไม่ได้ | ค่าเที่ยว 0 / ไม่มีทะเบียน / ไม่พบประเภทรถ / มีลิตรแต่ไม่มีเรท → **ไม่ถูกนับ** ในยอดขาย รายจ่าย รายได้ จนกว่าจะแก้ข้อมูล ยกเว้น **เที่ยวที่ 2 ขึ้นไปที่ค่าเที่ยว 0 และเบี้ยเลี้ยง 0** ซึ่งนับได้: ยอดขาย 0 แต่นำค่าน้ำมันไปหักเป็นรายจ่าย (รถบริษัท: รายได้ = −ค่าน้ำมัน, รถร่วม/หุ้นส่วน/อู่เสริม: 0) |

## 2. ตั้งราคาน้ำมันประจำวัน

**เมนู ตั้งค่า → ตั้งค่าน้ำมัน** หรือปุ่ม **ตั้งค่าน้ำมัน** ที่หน้า Booking (มุมขวาบน)

1. เลือก **วันที่ราคามีผล** แล้วกรอกราคา (บาท/ลิตร) ของประเภทรถที่เปลี่ยน ช่องที่เว้นว่าง = ใช้ราคาก่อนหน้าต่อ
2. กด **บันทึกราคาของวันที่นี้** ระบบคำนวณเรทน้ำมันของงานตามวันที่สร้างงานให้ใหม่ งานของวันอื่นไม่เปลี่ยน และ **งานที่จ่ายรายได้ให้คนขับแล้ว** (เอกสารรายได้คนขับจ่ายแล้ว หรือติ๊ก "จ่ายแล้ว" ของรอบเดือนนั้น) จะคงเรท ณ ตอนนั้นไว้ ไม่ถูกคำนวณใหม่
3. ตารางด้านล่างเป็นประวัติราคา แก้ไข/ลบรายการได้
4. **ควรตั้งราคาก่อนนำเข้างานทุกวัน** หน้านำเข้า Excel และปุ่มตั้งค่าน้ำมันจะมีจุด/แถบเตือนเมื่อวันนี้ยังไม่มีราคา

งานที่กรอกเรทเอง (ที่การ์ดงานหรือหน้าแก้ไขงาน) จะถูกล็อก ระบบไม่คำนวณทับ กรอก 0 หรือกด "ใช้ราคาประจำวัน" เพื่อปล่อยให้ระบบคำนวณใหม่

## 3. หน้า Booking (Fleet Cements / Ceramics)

- **กดแถวงาน** → การ์ดด้านบนแสดง ชื่อ-นามสกุลคนขับ · ทะเบียน · ชื่องาน · เรทน้ำมัน (พร้อมวันที่ของราคา) แก้เรทเฉพาะงานนั้นได้
- **จัดรถ/ส่งงาน**: ป๊อปอัพมีสรุป คนขับ/ทะเบียน/หน้างาน/ยอดเติมน้ำมัน · พิมพ์ค้นหาทะเบียนหรือชื่อคนขับได้ · ต้องเลือกคนขับก่อนกด "ส่งงาน"
- **งานไม่มีชื่อคนขับ**: ช่องคนขับแสดงหมายเหตุ + ปุ่ม "อัปเดต: [คนขับประจำรถ]" หรือเลือกคนขับเอง
- **เที่ยวที่**: ตั้งได้ 3 ที่ — คอลัมน์ "เที่ยวที่" ใน Excel/พรีวิวนำเข้า, ช่องเลือก "เที่ยวที่" ในตารางงาน และช่อง "เที่ยวที่" ในป๊อปอัพจัดรถ แอปคนขับเรียงตามเลขนี้และให้กด "ยืนยัน" เที่ยวเลขน้อยสุดก่อน **จ่ายเที่ยว 2 ก่อนเที่ยว 1 ก็ได้** เสมียนเลือกเที่ยวให้ **งานที่จ่ายไปแล้ว/งานเก่าที่ยังไม่มีเลข** ได้จากช่องในตารางงาน (ทุกงานที่ยังไม่ส่งเสร็จ) ถ้าเลขซ้ำกับงานอื่นของคนขับวันเดียวกัน ช่องจะเป็นสีแดง
- **ลิงก์ GPS หน้างาน**: ใส่ในคอลัมน์ "พิกัด/ลิงก์ Google Maps หน้างาน" (ชื่อคอลัมน์ใกล้เคียง เช่น GPS / ลิ้งค์GPS / Google Map ก็อ่านได้ รวมลิงก์ที่ฝังเป็น hyperlink) คนขับเห็นปุ่ม "นำทาง" ที่ขั้นส่งของแต่ละจุด
- **นำเข้า Excel**: ปุ่ม "นำเข้า Excel" (ดูหัวข้อ 4 ถ้าไม่อยากกรอกลงไฟล์)
- **ตรวจก่อนนำเข้า**: หน้าพรีวิวมีคอลัมน์ "ตรวจก่อนนำเข้า" เตือนพิกัด/ลิงก์ GPS ที่น่าสงสัย (ไม่ใช่ลิงก์/พิกัด, หลายลิงก์, ไม่ใช่ลิงก์แผนที่, พิกัดนอกประเทศไทย) เลขเที่ยวอ่านไม่ได้ และเลขเที่ยวซ้ำกับงานเดิมของคนขับวันนั้น กดยืนยันสร้างงานจะถามอีกครั้งถ้ามีแถวที่ควรตรวจ ข้อเตือนเหล่านี้ไม่ถูกบันทึกลงหมายเหตุของงาน
  - ชื่อเล่นสะกดต่างเล็กน้อย (แจ๊ค/แจ็ค) และทะเบียนที่มีจังหวัดต่อท้ายจับคู่ได้
  - ไม่ได้ระบุคนขับ/ชื่อเล่นไม่ตรง แต่ทะเบียนมีคนขับประจำ → ใช้คนขับประจำรถ พร้อมคำเตือน "ตรวจคนขับ" ให้ยืนยัน
  - ช่องน้ำมัน: ตัวเลข = ลิตร · ว่าง = ใช้ลิตรมาตรฐาน · "ไม่เติม" = 0 ลิตรโดยตั้งใจ · "38 ก๊าซ" = 38 + หมายเหตุ · "38-21" = 17
- **ลบงาน**: ผู้ดูแลระบบลบได้ทุกงาน · เสมียนลบได้เฉพาะงานที่ยังไม่วางบิลและไม่มีใบวางบิล/ใบแจ้งหนี้อ้างอิง

### การจบงาน (ต้องข้อมูลครบ)
เมนู ⋮ → **จบงาน** จะกดได้เมื่อมี ทะเบียน · คนขับ · ค่าเที่ยว > 0 (**ข้อยกเว้น: เที่ยวที่ 2 ขึ้นไปของคนขับในวันนั้น ที่ค่าเที่ยว 0 และเบี้ยเลี้ยง 0 ทั้งคู่ จบ/ยืนยัน POD/ยืนยันการจบงานได้** — เที่ยวแรกยังต้องมีค่าเที่ยว) ในไดอะล็อกจบงานต้องกรอก:
- เลขไมล์สิ้นสุด **ไม่บังคับ** (ชั่วคราว) แต่ถ้ากรอกต้องมากกว่าเลขไมล์เริ่มต้น
- **ลิตรน้ำมัน** หรือติ๊ก **"ไม่เติมน้ำมัน"** (รถที่ไม่ได้เติม) · ถ้ามีลิตรต้องมีเรทน้ำมัน
ข้อมูลไม่ครบ ปุ่มยืนยันจะกดไม่ได้และบอกว่าขาดอะไร เช่นเดียวกับ "ยืนยันการจบงาน" หลังตรวจ POD

## 4. ตารางลงงาน (กรอกแทนไฟล์ Excel)

**หน้า Booking → ปุ่ม ตารางลงงาน**

1. เลือก **วันที่ลงงาน** แล้วกรอก/วางข้อมูลเป็นตาราง (คัดลอกช่วงเซลล์จาก Excel แล้ว Ctrl+V ในช่องแรก ระบบเพิ่มแถวให้เอง)
2. **เพิ่มคอลัมน์** ได้ (ค่าจะต่อท้ายหมายเหตุของงานเป็น "ชื่อคอลัมน์: ค่า")
3. คอลัมน์ **ผลตรวจ** บอกคำเตือนของแต่ละแถวทันที (คนขับ, ลูกค้า, น้ำมัน, ราคาผิดปกติ) ตรงกับที่จะเห็นตอนนำเข้าจริง
4. เลือก **ดาวน์โหลด Excel** (รูปแบบเดียวกับไฟล์นำเข้า) หรือ **สร้างงานเข้าระบบ** (ไปหน้าพรีวิวนำเข้าเดิม ตรวจแล้วยืนยัน)
5. ฉบับร่างถูกเก็บในเครื่องอัตโนมัติ ปิดหน้าแล้วกลับมาต่อได้

## 5. ผู้ใช้งานและบุคลากร

**เมนู ตั้งค่า → สมุดรายชื่อ → ผู้ใช้งานและบุคลากร** (หน้าเดียวแทน จัดการผู้ใช้ / เสมียน / พนักงานขับรถ)

- ตารางเดียวรวมทุกคน แยกกลุ่มด้วย **Role**: ผู้ดูแลระบบ · เสมียน · ผู้จัดรถ · พนักงานขับรถ · บัญชี (ชิปด้านบนแสดงจำนวน) + ช่องค้นหา ชื่อ/ชื่อเล่น/รหัส/อีเมล/ทะเบียน
- ปุ่ม **เพิ่ม** → เลือก ผู้ใช้งานระบบ / เสมียน / พนักงานขับรถ
- ต่อแถว: **รายละเอียด** (คนขับ) · **แก้ไข** · **บัญชี** (แก้บัญชี login ของคนที่มีทั้งทะเบียนและบัญชี) · **ลบ** · เมนู ⋮ (รีเซ็ตรหัสผ่าน ปิด/เปิดบัญชี ลบบัญชี)
- **ลบพนักงานขับรถ**: ระบบเตือนจำนวนงาน/บัญชี login/รถประจำก่อนยืนยัน ถอดรถประจำให้ แต่ **ไม่ลบบัญชี login** ต้องปิด/ลบบัญชีเอง · ชื่อคนขับที่เก็บในงานเก่ายังอยู่
- ผู้จัดรถเห็น/จัดการเฉพาะกลุ่มพนักงานขับรถ

## 6. ตรวจข้อมูลคนขับในงาน

**เมนู ตั้งค่า → สมุดรายชื่อ → ตรวจข้อมูลคนขับในงาน** รวมงานที่ข้อมูลคนขับไม่ตรง/ไม่ครบ พร้อมลิงก์ **ดูงาน / แก้ไขงาน**

| กลุ่ม | วิธีแก้ |
|---|---|
| งานที่ไม่มีชื่อคนขับ | ปุ่ม "อัปเดต" (คนขับประจำรถ) หรือเลือกคนขับเอง |
| ชื่อคนขับในงานไม่ตรงกับทะเบียนคนขับ | ปุ่ม **ซิงก์จากทะเบียนคนขับ** |
| งานนำเข้าเก่าที่ยังไม่มีชื่อ/นามสกุลแยก | ปุ่มซิงก์ (เงินเดือนคนขับใช้ชื่อแยกนี้) |
| หมายเหตุ "ชื่อเล่นไม่ตรง" ที่ค้างอยู่ | ปุ่มซิงก์ลบข้อความที่ค้างให้ |

"ซิงก์ทั้งกลุ่ม" ทำทุกงานในกลุ่มพร้อมกัน (ใช้เวลาสักครู่ อย่าปิดหน้า) ซิงก์ผูกด้วยรหัสคนขับ ไม่เปลี่ยนสถานะ/ทะเบียนของงาน

## 7. Dashboard

- **สถานะงาน**: รอจัดรถ · กำลังดำเนินการ/ขนส่ง · รอตรวจ POD · ส่งเสร็จเดือนนี้ (กดไปดูรายการ)
- **สรุปสถานะการเงิน**: เลือก **ประเภทงาน** และ **ช่วงวันที่** (ทั้งหมด / สัปดาห์นี้ [จันทร์–อาทิตย์] / เดือนนี้ / ไตรมาสนี้ / ปีนี้ / กำหนดเอง) นับตามวันที่ส่งของเสร็จ
- **ต้องดำเนินการ**: รายการข้อมูลที่ยังไม่ครบ กดแล้วพาไปหน้าที่ **กรองเฉพาะเรื่องนั้นให้แล้ว** (ราคาน้ำมันวันนี้, งานไม่มีชื่อคนขับ, งานไม่มีทะเบียน, งานที่ยังไม่ระบุราคา แยกกองรถ, ข้อมูลคนขับต้องซิงก์ แยก 3 เรื่อง, งานมีลิตรแต่ไม่มีเรท, งานคิดเงินไม่ได้, รอตรวจ POD แยกกองรถ, คนขับทดสอบ)
- **ตัวกรองราคา**: หน้า Booking กรอง "ยังไม่ระบุราคา / ระบุราคาแล้ว" และช่วงราคาได้ หน้า "งานเสร็จสิ้น" กรอง "ยังไม่ระบุราคา" ได้ และกรอง "คิดเงินไม่ได้" ได้
- **กราฟ ยอดขาย รายจ่าย รายได้บริษัท**: ชี้เมาส์ที่เดือนใดเพื่อดูตัวเลขของทุกซีรีส์ (มือถือแตะค้างไว้) มีตัวกรองประเภทงานและช่วงวันที่ของตัวเอง
- **ราคาน้ำมันวันนี้**: ราคาตามประเภทรถ พร้อมวันที่ราคามีผล

## 8. คำถามที่พบบ่อย

**ทำไมงานเก่าขึ้น "ยังไม่มีเรท"?** ยังไม่มีราคาน้ำมันที่วันที่สร้างงานนั้น (หรือก่อนหน้า) ให้เพิ่มราคาในหน้าตั้งค่าน้ำมัน

**ทำไมกดจบงานไม่ได้?** ดูข้อความสีแดงในไดอะล็อก หรือเอาเมาส์วางที่เมนู จบงาน (ขาดทะเบียน/คนขับ/ค่าเที่ยวต้องไปแก้ที่หน้าแก้ไขงาน/จัดรถก่อน)

**งานไม่ถูกนับในยอดการเงิน?** ดู "ต้องดำเนินการ → งานที่ยังคิดเงินไม่ได้" ที่ Dashboard มีสาเหตุแยกให้

**กรอกเรทน้ำมันเองแล้วเปลี่ยนไม่ได้?** งานที่กรอกเรทเองถูกล็อก กรอก 0 หรือกด "ใช้ราคาประจำวัน" เพื่อให้ระบบคำนวณใหม่
